# Git and GitHub Collaboration Lab

**Course:** CSE103  
**Lab:** LAB 3 – GitHub Collaboration and API Interaction  
**Repository:** `cse103-lab-LAB3`

## Overview
This repository demonstrates basic Git repository management, connecting a local repository to GitHub, pushing and pulling changes, and writing clear project documentation with Markdown.

## Objectives
- Install and verify Git.
- Configure Git user identity and the default branch.
- Create and manage a local Git repository.
- Connect the local repository to a GitHub remote.
- Push local commits and pull remote changes.
- Use Markdown headings, lists, code, links, tables, blockquotes, and horizontal rules.

## Repository Contents
| File | Purpose |
|---|---|
| `README.md` | Project overview and instructions |
| `main.py` | Small Python example |
| `MARKDOWN_GUIDE.md` | Markdown syntax reference |
| `CHANGELOG.md` | Record of project changes |
| `.gitignore` | Files and folders Git should ignore |

## Getting Started
1. Install Git.
2. Clone this repository or download the project files.
3. Open a terminal in the project directory.
4. Run the example:

```bash
python3 main.py
```
