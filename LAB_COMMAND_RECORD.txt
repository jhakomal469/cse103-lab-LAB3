5. Create the GitHub repository in your own account

6. Connect and push (replace URL with your actual repository URL)

git status

10. Remote workflow summary
git remote add origin <URL>   — connect local repository to GitHub
git remote -v                 — list configured remotes
git push -u origin main       — push and set upstream
git push                      — push later commits
git pull                      — fetch and merge remote changes
git fetch origin              — fetch without merging
git clone <URL>               — copy a remote repository locally
